# Brand Direction — “The Alchemist” (locked)

The core brand direction was locked on June 1, 2026. This page you are reading is built in it — treat the page itself as a living style reference.

## Type system

| Role | Typeface | Usage |
|------|----------|-------|
| Display | Cormorant Garamond | Headlines, ritual copy, large numerals. Wide letter-spacing on caps. |
| Body | DM Sans | Paragraphs, UI labels, buttons. Light weights preferred. |
| Mono | Fira Code | Data, wallet addresses, eyebrows, metadata, countdowns. |

## Color

| Token | Hex | Role |
|-------|-----|------|
| Background | `#080504` | Near-black, warm — never pure black |
| Gold | `#C9A96E` | Primary accent: borders, links, numerals |
| Off-white | `#EDE8E0` | Primary text |
| Secondary | `#B8A88A` | Secondary text |
| Ember | `#E25822` | Fire moments only — burns, warnings, live flame. Use sparingly. |

## Style rules

- **Hairline gold borders** (1px, low opacity) instead of cards with fills and shadows.
- **Ghost buttons** — transparent with gold hairline, gold fill on hover.
- Wide letter-spacing on display caps and mono eyebrows.
- Film grain and candlelight radial glows for atmosphere; never flat solid panels.
- Generous negative space. Density is for data tables, not layouts.
